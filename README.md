## Опис

Предметну частину перебудовано для варіанта 17 — «Спортивна ліга».
Рядок CSV перетворюється на незмінний об'єкт-сутність `Match`.
Його конструктор виконує мінімальну предметну валідацію, а допоміжні
показники матчу зберігаються у `ScoreAttendance`.

Програма читає список результатів матчів спортивної ліги з CSV-файла, перевіряє коректність кожного запису, обчислює статистичні показники та формує текстовий звіт у консоль і файл.

Невалідні рядки не зупиняють виконання програми. Для кожного некоректного запису виводиться номер рядка та причина помилки.

## Формат запису

Кожен рядок вхідного файлу має 5 полів, розділених крапкою з комою `;`:

```text
home;away;homeScore;awayScore;attendance
```

де:

- `home` — назва домашньої команди;
- `away` — назва гостьової команди;
- `homeScore` — кількість голів домашньої команди;
- `awayScore` — кількість голів гостьової команди;
- `attendance` — кількість глядачів на матчі.

Текстові поля є обов'язковими.

Числові поля повинні містити цілі невід'ємні значення.

Файл кодується у UTF-8.

## Показники

Програма обчислює:

1. кількість коректних записів;
2. середню кількість голів за матч;
3. найбільшу відвідуваність;
4. сумарну відвідуваність.

Невалідні записи пропускаються, але інформація про помилки зберігається у звіті.

## Приклад вхідних даних

Файл `data/input.csv`:

```text
Динамо;Шахтар;2;1;12500
Карпати;Зоря;1;1;8500
Полісся;Верес;3;0;10200
Рух;Олександрія;0;2;7300
Львів;Ворскла;2;2;6800
Чорноморець;Колос;1;0;5400
Минай;Дніпро-1;0;3;7200
Оболонь;Кривбас;1;2;6100
;Шахтар;2;1;5000
Динамо;Карпати;abc;1;7000
Рух;Верес;-1;2;4500
Полісся;Зоря;2;1
```

Перші 8 записів є коректними.

Рядки 9–12 містять помилки:

- порожня назва команди;
- неправильний числовий формат;
- від'ємне числове значення;
- неправильна кількість полів.

## Структура програми

- `Main.java` — точка входу та обробка аргументів командного рядка;
- `Match.java` — незмінна сутність матчу з інкапсульованим станом,
  конструктором валідації та фабрикою `fromCsv`;
- `ScoreAttendance.java` — допоміжний record із показниками рахунку та відвідуваності;
- `CsvProcessor.java` — обробка рядків, агрегація показників і помилок;
- `ReportResult.java` — зберігання результатів обробки;
- `ReportGenerator.java` — формування текстового звіту;
- `CsvProcessorTest.java` — тести обробки CSV;
- `MatchTest.java` — тести предметної валідації сутності;
- `ReportGeneratorTest.java` — тести формування звіту.

Потік даних:

```
data/input.csv
      ↓
CsvProcessor
      ↓
ReportResult
      ↓
ReportGenerator
      ↓
консоль + out/report.txt
```

### Відмінності від лабораторної роботи №1

У попередній роботі CSV-рядок розбирався безпосередньо в
`CsvProcessor`, а показники накопичувалися паралельними змінними.
Тепер `Match.fromCsv` створює сутність і централізовано виконує розбір
та валідацію. Стан `Match` зберігається у `private final` полях без
setter-ів. Показники одного матчу представлені незмінним
`ScoreAttendance`, а зовнішній CSV і звіт залишилися без змін.

## Збірка та запуск

Перевірка проєкту:

### Windows

```powershell
mvnw.cmd -B clean verify
```

Збірка JAR:

```powershell
mvnw.cmd -B package
```

Запуск:

```powershell
java -jar target/cppt-labs.jar
```

Запуск із власним вхідним файлом:

```powershell
java -jar target/cppt-labs.jar --input data/input.csv
```

Запис звіту у файл:

```powershell
java -jar target/cppt-labs.jar --input data/input.csv --output out/report.txt
```

## Параметри командного рядка

- `--help` — показати довідку;
- `--version` — показати версію;
- `--input FILE` — шлях до вхідного CSV-файла;
- `--output FILE` — шлях до файла звіту.

За замовчуванням:

```text
input  = data/input.csv
output = out/report.txt
```

## Тестування

Запуск JUnit-тестів:

```powershell
mvnw.cmd -B test
```

Перевіряються:

- коректні записи;
- порожній рядок;
- неправильна кількість полів;
- нечислове значення;
- від'ємне значення;
- порожня назва команди;
- формування звіту;
- випадок, коли немає коректних записів;
- створення `Match` через конструктор і `fromCsv`;
- нульові граничні значення;
- некоректні CSV-значення;
- стабільне `toString`;
- значення `ScoreAttendance`.
