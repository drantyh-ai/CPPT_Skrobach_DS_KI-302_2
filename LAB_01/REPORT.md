# Звіт до лабораторної роботи №1

## 1. Тема, номер і варіант

**Тема:** Розгортання Java-проєкту та базова обробка даних
**Лабораторна робота:** №1
**Варіант:** 17
**Предметна область:** Спортивна ліга
**Операційна система:** Windows 11
**Java:** 21

## 2. Мета роботи

Створити консольну Java-програму, яка читає, перевіряє та обробляє текстові записи, обчислює задані показники й формує звіт.

## 3. Постановка задачі

Формат одного запису:

```text
home:String; away:String; homeScore:int; awayScore:int; attendance:int
```

Необхідно обчислити:

1. кількість коректних записів;
2. середню кількість голів;
3. найбільшу відвідуваність;
4. сумарну відвідуваність.

Некоректні записи не повинні завершувати роботу програми. Повідомлення про помилку містить номер рядка та причину.

## 4. Структура програми

Основний клас:

```text
ua.lpnu.kzp.lab01.Lab01
```

Основний порядок роботи:

```text
input.csv → читання → перевірка → обчислення → звіт
```

Вхідні дані зберігаються у `data/input.csv`, результат — у `out/report.txt`.

## 5. Інфраструктура

Для збирання використовується Maven.

У проєкті налаштовано:

* Java 21;
* JUnit 5;
* SpotBugs;
* Maven Wrapper;
* створення виконуваного JAR;
* кодування UTF-8.

Основні команди:

```powershell
mvn test
mvn verify
mvn package
```

Запуск програми:

```powershell
java -jar target\lab01-1.0.0.jar
```

Перевірка версії:

```powershell
java -jar target\lab01-1.0.0.jar --version
```

## 7. Приклади роботи

Приклад коректних записів:

```text
Карпати;Динамо;2;1;15420
Шахтар;Полісся;3;0;18250
Рух;Зоря;1;1;8430
Львів;Верес;2;3;6120
```

Приклад некоректних записів:

```text
Карпати;Зоря;помилка;1;9500
Шахтар;Рух;-1;2;11000
```

Результат:

```text
Коректних записів: 4
Середня кількість голів: 3.25
Найбільша відвідуваність: 18250
Сумарна відвідуваність: 48220
```

Помилки виводяться із зазначенням номера рядка та причини.

## 8. Тестування

Перевірено:

* коректні записи;
* порожній рядок;
* неправильну кількість полів;
* неправильне числове значення;
* від'ємні значення;
* обчислення середнього;
* українські символи.

Результати команд:

```text
mvn test   — BUILD SUCCESS
mvn verify — BUILD SUCCESS
mvn package — BUILD SUCCESS
```
