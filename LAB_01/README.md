# Лабораторна робота №1 — Спортивна ліга

## Призначення програми

Програма призначена для обробки даних про матчі спортивної ліги.

Програма:

* читає записи з CSV-файла;
* перевіряє коректність кожного запису;
* пропускає некоректні записи з повідомленням про причину помилки;
* обробляє всі коректні записи;
* обчислює задані статистичні показники;
* виводить звіт у консоль;
* зберігає звіт у текстовий файл.

### Формат одного запису

```text
home;away;homeScore;awayScore;attendance
```

Типи полів:

```text
home:String
away:String
homeScore:int
awayScore:int
attendance:int
```

Наприклад:

```text
Карпати;Динамо;2;1;15420
```

## Показники

Програма обчислює чотири показники:

1. Кількість коректних записів.
2. Середня кількість голів.
3. Найбільша відвідуваність.
4. Сумарна відвідуваність.

Для обчислення середньої кількості голів використовується загальна кількість голів у коректних матчах, поділена на кількість коректних записів.

## Запуск

Перевірка компіляції:

```powershell
mvn clean compile
```

Запуск тестів:

```powershell
mvn test
```

Повна перевірка:

```powershell
mvn verify
```

Створення JAR:

```powershell
mvn package
```

Після створення JAR:

```powershell
java -jar target\lab01-1.0.0.jar
```

### Довідка

```powershell
java -jar target\lab01-1.0.0.jar --help
```

### Версія

```powershell
java -jar target\lab01-1.0.0.jar --version
```

### Власний вхідний файл

```powershell
java -jar target\lab01-1.0.0.jar --input data\input.csv
```
